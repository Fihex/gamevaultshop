### 1. Java (Spring Boot)

In Java, we use a **CRON expression**.

**File:** `service/ImageCleanupService.java`

Find this line:
```java
@Scheduled(cron = "0 0 3 * * ?")
```

**The format is:** `Seconds Minutes Hours Day Month Weekday`

**Examples:**
*   **Run at 5:00 AM:**
    `@Scheduled(cron = "0 0 5 * * ?")`
*   **Run at 1:30 PM (13:30):**
    `@Scheduled(cron = "0 30 13 * * ?")`
*   **Run every 12 hours:**
    `@Scheduled(cron = "0 0 */12 * * ?")`

---

#### PRO TIP: Move it to Config (Recommended)
Instead of hardcoding it, put the value in your `application.properties` file so you can change it without recompiling.

1.  **Change Java Code:**
    ```java
    // Read from config, default to 3 AM if missing
    @Scheduled(cron = "${app.cleanup.cron:0 0 3 * * ?}")
    public void cleanupOrphanedImages() { ... }
    ```

2.  **Add to `application.properties`:**
    ```properties
    app.cleanup.cron=0 0 5 * * ?
    ```

### 2. Go (Golang)

In Go, the `time.NewTicker(24 * time.Hour)` just waits 24 hours *from the moment the app started*. It doesn't know what "3 AM" is.

To run at a specific wall-clock time (e.g., 03:00), you must calculate the delay until the *next* 3 AM, wait for that, and *then* start the 24-hour ticker.

**File:** `services/cleanup_service.go`

Replace your `StartCleanupTask` with this updated version:

```go
func StartCleanupTask() {
	// ... (Toggle switch logic remains the same) ...

	fmt.Println("--- [CRON] Service Started. Will run on schedule. ---")

	go func() {
		// 1. OPTIONAL: Run immediately on startup?
		// cleanOrphanedFiles() 

		// 2. Calculate time until next 3:00 AM
		now := time.Now()
		
		// Set target to today at 3:00:00
		nextRun := time.Date(now.Year(), now.Month(), now.Day(), 3, 0, 0, 0, now.Location())
		
		// If 3 AM passed already today, schedule for tomorrow
		if nextRun.Before(now) {
			nextRun = nextRun.Add(24 * time.Hour)
		}

		fmt.Printf("--- [CRON] Next run scheduled for: %v ---\n", nextRun)

		// 3. Sleep until that time
		time.Sleep(time.Until(nextRun))

		// 4. Execute the first scheduled run
		cleanOrphanedFiles()

		// 5. Start the 24-hour ticker for future runs
		ticker := time.NewTicker(24 * time.Hour)
		for range ticker.C {
			cleanOrphanedFiles()
		}
	}()
}
```

**To change the time in Go:**
Change the numbers in this line:
`time.Date(..., 3, 0, 0, 0, ...)`
*(Hour, Minute, Second, Nanosecond)*

For **5:30 PM**, you would use:
`time.Date(..., 17, 30, 0, 0, ...)`
